# 坦克大战 Tank Battle

经典红白机风格的 HTML5 坦克大战游戏，纯单文件实现，无需任何依赖，打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作方式

| 按键 | 功能 |
|------|------|
| ↑ / W | 向上移动 |
| ↓ / S | 向下移动 |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| 空格 | 射击 |
| P | 暂停 / 继续 |
| 触屏 | 手机/平板上自动显示虚拟方向键、开火键和暂停键 |

## 道具系统

击毁敌方坦克有概率掉落道具，驾驶坦克压上去即可拾取：

| 道具 | 效果 |
|------|------|
| ⭐ 星星 | 火力升级（子弹更快、可同时发射更多、射速更高，最高 3 级） |
| 🛡️ 护盾 | 10 秒无敌 |
| ❤️ 生命 | 增加一条命 |
| 💣 炸弹 | 立即消灭屏幕上所有敌人 |
| ⛏️ 铲子 | 基地周围变为钢墙，持续 20 秒 |

## 游戏规则

- 🎯 消灭所有敌方坦克即可进入下一关
- 🦅 保护底部的金色老鹰基地，基地被毁即失败
- 🧱 砖墙可以被子弹击破，钢墙无法摧毁
- ❤️ 玩家共有 3 条生命，被击中即损失一条（火力等级重置）
- 🏆 击杀敌人 +100 分，拾取道具 +50 分，过关 +500 分

## 技术说明

- 纯 HTML / CSS / JavaScript，单文件，零依赖
- 基于 Canvas 渲染，瓦片地图（13×13）
- 敌方坦克具备简单 AI：随机移动、追踪基地、主动开火
- 包含粒子爆炸特效、出生护盾、关卡递进等机制
- 支持手机触屏操作（虚拟方向键 + 开火键），并内置道具系统
- 在线试玩：https://sterrr-17.github.io/tank-battle/

## 本地运行

```bash
# 直接双击打开，或启动一个本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```
