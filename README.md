# 坦克大战 Tank Battle

经典红白机风格的 HTML5 坦克大战游戏，纯单文件实现，无需任何依赖，打开即玩。

## 在线试玩

直接用浏览器打开 `index.html` 即可开始游戏。

## 操作方式

| 按键 | 功能 |
|------|------|
| ↑ / W | 向上移动 |
| ↓ / S | 向下移动 |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| 空格 | 射击 |
| P | 暂停 / 继续 |

## 游戏规则

- 🎯 消灭所有敌方坦克即可进入下一关
- 🦅 保护底部的金色老鹰基地，基地被毁即失败
- 🧱 砖墙可以被子弹击破，钢墙无法摧毁
- ❤️ 玩家共有 3 条生命，被击中即损失一条
- 🏆 击杀敌人 +100 分，过关 +500 分

## 技术说明

- 纯 HTML / CSS / JavaScript，单文件，零依赖
- 基于 Canvas 渲染，瓦片地图（13×13）
- 敌方坦克具备简单 AI：随机移动、追踪基地、主动开火
- 包含粒子爆炸特效、出生护盾、关卡递进等机制

## 本地运行

```bash
# 直接双击打开，或启动一个本地服务器
python -m http.server 8000
# 然后访问 http://localhost:8000
```
